# 北京新高考英语听说冲刺：朗读短文评分重建

这个仓库整理对本机「北京新高考英语听说冲刺 → 朗读短文」评分流程的静态逆向结果，并用 Python 实现**已经确认的数学步骤**。它不是原程序的源码，也不能直接从 WAV 复现完整成绩：音频对齐、模型全部输入特征、特殊词处理及部分运行时参数尚未全部恢复。

研究对象为学生端 6.12.1.173、本地语音引擎 4.4.2；抽查题型为 `PART_A / ParagraphReadAloud`，题目满分 8 分。结果来自原始安装文件、已有日志和 DLL 反汇编；没有新录音或运行评分引擎。

## 快速使用

需要 Python 3.9 或以上，无第三方依赖。在本目录执行：

```powershell
python -m oral_scoring
python -m unittest discover -s tests -v
```

如本机仍安装原程序，可只读解析本机模型和特征配置。运行时输入一次 `client` 目录，程序会使用其下的相对路径：

```powershell
python -m oral_scoring --client-dir (Read-Host '请输入 client 目录')
```

这会校验封装长度、模型类型和支持向量数量，并输出维度、核参数；不会运行或修改原程序，也不会上传数据。原程序模型属于独立文件，本仓库没有打包它们。Python 使用双精度浮点数，原引擎部分步骤使用 float32，因此结果不保证逐位一致。

## 从录音到音素

题目提供原文和对应 net 文件，录音经过声学特征提取、本地 Kaldi Nnet3 模型及 `FA` 强制对齐，得到与词和音素对应的解码路径。路径非零输入标签弧的第二个权重被提取，按当前模型的 `acoustic-scale` 取负、缩放，形成评分器使用的逐帧 GOP：

```text
frame_gop[t] = -路径弧第二权重[t] / acoustic_scale
phone_gop = sum(frame_gop[t] for t 属于该音素) / 帧数
```

路径权重和评分器之间的静态复制链见 [证据记录](evidence/gop-decoder-chain.md) 与 [GOP 数据传递](evidence/frame-gop-data-bridge.md)。本机 `recognition/parta/online.conf` 写的是 `acoustic-scale=1.0`，但没有本次运行最终内存值。路径权重的声学分量解释参考 Kaldi 的 LatticeWeight 结构；本题是否使用已单独追到的神经网络缓存分支尚未完全绑定，不能把这里的 GOP 直接说成音素后验概率比。

原始音素 GOP 经下述普通标准化分支得到百分制音素分：

```text
z = (phone_gop - mean) / scale
phone_score = max(0, 100 - 10 * min(0, z)^2)
```

`mean`、`scale` 由题型和评分档位选择，本次运行值尚未完整确认；特殊音素存在额外分支。详见 [音素代码证据](evidence/gop-phone-evidence.md)。

## 单词评分

普通路径把一个词对应的**百分制音素分**求平均：

```text
word_score = sum(phone_score) / 音素数量
```

例如已有结果中 `others` 的音素分为 51.95、59.36、61.81、88.22、86.22，平均约 69.51；引擎返回的该词 `score` 为 69.51。特殊词或标记还有其他处理：在抽查的 134 个词中，3 个返回分与所公布音素分的简单平均明显不同，不能把普通公式当作完整通用公式。

前端使用 `words[].score` 为单词上色：低于 50 红色，50 到低于 80 黑色，80 及以上绿色；拒评时有单独显示分支。这个证据证明颜色如何决定，不能单独证明所有界面都显示逐词数字。

## 句子发音分

普通路径构造 14 维特征，使用配置的 `pron_score.mean` 和 `pron_score.scale` 标准化：

```text
z[i] = (feature[i] - mean[i]) / scale[i]
```

特征中已有证据的项目包括：有效词中词分 >80、50<分数≤80、≤50 的比例，以及部分选中词的原始 GOP 和百分制词分均值。还有按内部数组项数设置的标记；部分维度及筛选/回退语义尚未完全恢复。[14 维证据与限制](evidence/pronunciation-features-notes.md)

标准化后输入对应评分档位的本地 RBF epsilon-SVR；本次已有日志记录使用 `svm_accuracy_normal.model`，模型含 24,782 个支持向量、`gamma=1/14`。代码中的通用预测式为：

```text
prediction = Σ coefficient[j] × exp(-gamma × ||z - support_vector[j]||²) - rho
```

预测之后还有内部比例和标记处理，相关参数来源未完全绑定；不要直接把 `prediction` 当百分制发音分。完整从录音计算出 14 个输入仍未实现。

## 句子流利度

普通路径提取 6 维特征并按 `sentence_flu_score.mean/scale` 标准化，再输入 `svm-fluency.model`。该模型是 RBF epsilon-SVR，`gamma=0.05`，含 3,358 个支持向量。

代码可见的 6 个数值依次包括：筛选条目的数量比例、筛选长度的方差、`len(D)/(0.03*sum(D))`、句速函数输出、`0.03*D` 的标准差、筛选长度之和与 `sum(D)` 的比例。这里 D 是内部音素相关帧长度列表；各输入数据及筛选语义尚未全部确认，不应随意命名为停顿次数等。

成功预测后的可见代码，保留未绑定字段：

```text
m = 内部比例字段
t = clamp(prediction, 0, m) * m
if t > 75:
    t = min(100, 2*t - 75)
sentence_fluency = 内部句子乘数 * t
```

内部比例字段和句子乘数的来源尚未完全绑定；部分数据量不足的条件会回退到发音相关数值，故上述不是所有句子的通用路径。详见 [流利度证据](evidence/fluency-evidence-limits.md)。

## 句子完整度

对于有词位的普通路径，`N` 为句子单词分数组长度，`M` 为内部对齐结果中标记为 `##` 的词位数，`Z` 为 0 分词位数：

```text
invalid = Z if Z > N / 2 else M
completion = 100 * (N - invalid) / N
```

例如 N=10、M=3、Z=2 时为 70；N=10、M=3、Z=6 时为 40。Z 恰好为 N 的一半时不触发替换。`##` 的每一种成因尚未完全确认，不能把它无条件等同于漏读；空句等边界也尚未完整还原。

## 句子总分

普通长句（超过 3 词）：

```text
sentence = 0.8 * sentence_pronunciation + 0.2 * sentence_fluency
if completion <= 50:
    sentence *= completion / 75
sentence = clamp(sentence, 0, 100)
```

最多 3 词的短句另有分支；本仓库不以长句公式冒充短句实现。已有样本第一句发音 78.87、流利度 100、完整度 100，用已显示的分项复算为约 83.096；应用返回 83.09。分项已经舍入或截取，不能用这个例子证明程序内部舍入方式。

## 篇章和最终题目分

本次题目没有开启前端指定句数的可选累加路径。引擎分别汇总句子发音、完整度和流利度，再加入两类低分词比例，做五项线性点积并限制到 0～100：

```text
features = [A, C, F, P50, P50_70]
base = clamp(dot(coefficients, features) + bias, 0, 100)
```

- A、C、F：句子发音、完整度、流利度的加权结果。本次 9 句都超过 3 词，权重为各句词数 / 134；短句、单句等另有分支。
- P50：经过特定词和标记过滤后，词分 ≤50 的比例。
- P50_70：同一集合中 50<词分≤70 的比例；分母是过滤后的有效词数。

本机配置中存在名为 `bj_paragraph_score_model` 的参数：

```text
coefficients = [0.77266539, 0.05508793, 0.18843264, -23.51403671, -15.79654803]
bias = 0.1992771
```

**这些数字确实由本机配置解包得到，但尚未完整证明它们被复制到本题选中的运行时评分成员。**因此它们只是本题的候选参数，不能当成已确认的本题公式。已披露的两位分数代入该组参数约得 72.795，与返回的 72.79 接近；因输入精度已损失，这不足以排除其他参数组。[完整证据及边界](evidence/outer-scoring-reconstruction.md)

引擎存在可选附加校准；已知当基础分超过该配置的 60 分阈值时会直接返回原分。本样本约 72.79，不受这条分支影响；60 分及以下的校准尚未完整恢复。该题前端将百分制分数乘以 `8/100`，再以一位小数展示：72.79 对应 5.8/8。拒评、多次录音择优和其他配置会有额外分支，不在通用复现范围。

## 模型与原始证据

以 `client` 为基准的原始模型目录：

```text
resources/plugins/ases/ia32/win32/model/score/readaloud
```

| 文件 | 内容 |
| --- | --- |
| `svm_accuracy_normal.model` | 本次记录的句子发音 RBF epsilon-SVR |
| `svm-fluency.model` | 句子流利度 RBF epsilon-SVR |
| `score-basic-feature.json` | 特征标准化参数与多组候选篇章系数 |

原件使用 `encr + 4 字节小端长度 + 逐字节 XOR` 封装；`oral_scoring.models.read_payload` 会在内存中解包并验证长度。[证据目录](evidence/)保留反汇编和独立审计笔记。反汇编中的安装位置已改为相对 `client` 的路径；构建机器的源码路径仅保留为标识，不代表 `client` 中存在该源码。历史日志位于独立的应用数据目录，也不属于 `client`。没有训练集、标签、完整音频特征过程或原始 C++ 源码，不能从模型文件倒推出这些资料。

## 已知限制

当前代码针对正常有限输入，是对已确认数学结构的重建，不是生产评分器，也不是官方实现。尚缺：完整 14/6 维输入语义和特征生成、音素/词特殊分支、部分运行参数的绑定、低分附加校准和本题篇章参数复制链。使用者必须提供代码无法从音频计算的中间输入。
